切换前准备
请先阅读
1
先在显卡驱动中创建自定义分辨率
Windows 只能切换到显卡驱动已支持的分辨率。请先在 NVIDIA 控制面板、AMD Software 或 Intel 显卡软件中，为需要的拉伸尺寸创建自定义分辨率。
2
将显卡缩放模式设为“全屏”
在同一显卡控制面板中，将缩放模式设为全屏（Full-screen），让画面铺满显示器。请勿选择“纵横比”或“居中”。
3
启动游戏前，点击“一键开启拉伸”
输入目标分辨率，点击上方一键开启拉伸，允许 Windows 管理员操作。程序会先禁用监视器，再应用分辨率；不需要打开设备管理器。请在操作完成后启动《无畏契约》。
4
设置游戏内的显示选项
显示模式：窗口化全屏（Windowed Fullscreen）。宽高比方式：填充（Fill）。
5
按需切换，结束后恢复桌面
若菜单或加载后需要重新切换，可使用默认快捷键 Ctrl + Alt + S 来回切分辨率；一键模式会继续保留监视器恢复记录。结束游戏后，点击一键恢复桌面，或保持软件运行并开启自动恢复。恢复监视器时仍可能出现 Windows 权限提示。游戏内拉伸效果需要在你的显卡和游戏设置下确认。
修复黑边
适用于部分笔记本
部分电脑使用自定义分辨率时，画面两侧会出现黑边。 此功能会将 Windows 注册表中的显示缩放设为全屏拉伸（Full Panel）， 让画面铺满显示区域。

⚠ 需要管理员权限，操作时会弹出 Windows 权限确认。
⚠ 应用后需要重启电脑。
并非适用于所有电脑，主要面向 Intel 和 AMD 集成显卡。 NVIDIA 用户请优先在NVIDIA 控制面板 → GPU 缩放 → 全屏中设置。
