## 直接使用

双击 `EasyTS-zh-CN.exe` 或分享版 `EasyTS一键版.exe` 即可启动，无需安装 Python。支持 Windows 10/11 的 x64 系统；需要 Microsoft WebView2 运行时。界面与作者头像均已内置，文字使用 Windows 系统字体，已有 WebView2 时可离线启动。联网时仅检查上游版本；点击“查看原版”会打开作者发布页，不会自动替换当前中文程序。

分享时可以只发送 `EasyTS一键版.exe`，不必附带源码、HTML、Python 或 DLL 文件。程序已将中文页面、Python、所需库及许可文本一并打包；运行时会自行解包到临时目录。也可发送 `EasyTS一键版-便携包.zip`，接收者解压后双击其中的 EXE。缺少 WebView2 时会提示安装，自动安装需要联网。

使用时请先退出英文版 EasyTS，避免两个窗口争用全局快捷键。中文版沿用 `%LOCALAPPDATA%\EasyTS` 中的设置、预设及分辨率恢复记录，不会替换英文版程序文件。旧设置中的开关状态会继续生效。

## 首次准备

1. 在 NVIDIA 控制面板、AMD 或 Intel 显卡软件中，创建需要的自定义分辨率。例如你使用的 `1566x1080`。EasyTS 负责切换已注册的分辨率，不负责创建显卡模式。
2. 将显卡缩放模式设为“全屏”。
3. 启动游戏前，在主界面输入目标分辨率，点击“一键开启拉伸”。允许 Windows 管理员操作后，程序先禁用当前已启用的监视器，再应用分辨率；无需打开设备管理器。
4. 完成后启动《无畏契约》，游戏内选择“窗口化全屏”和“填充”。具体拉伸效果仍取决于显卡缩放和游戏设置。
5. 常用分辨率和预设现在只会填入输入框；“仅切分辨率”保留单独切换能力，不会禁用设备。

## 切换与恢复

- 点击“一键恢复桌面”，先重新启用本次禁用的监视器，再还原最初保存的分辨率。开启前已经禁用的监视器会保持原状；如果你希望全部重新启用，请在结束一键模式后使用“监视器驱动 · 单独控制”。
- 默认自动恢复开启：保持软件运行，检测到《无畏契约》进程启动并退出后，执行完整恢复。若你曾关闭该设置，需要重新开启或手动点击“一键恢复桌面”。
- 开启和恢复都可能请求 Windows 管理员权限。取消开启时不会切换分辨率；恢复权限被拒绝或设备恢复失败时，记录会保留，按钮可再次重试。自动恢复不是绕过权限提示。
- 点击关闭按钮或按 Alt+F4 时，一键模式会先尝试恢复；失败时保留窗口。程序意外结束后，重新打开也可用恢复记录继续恢复。强制结束或断电期间无法执行恢复。
- 默认快捷键 `Ctrl + Alt + S` 在原分辨率和上次拉伸分辨率之间切换，便于游戏菜单与对局间切换；它只操作分辨率，一键模式的监视器恢复记录仍会保留。
- “设置 → 分辨率切换快捷键 → 更改”支持 F1–F11、A–Z、0–9，可搭配 Ctrl、Alt、Shift；按 Esc 取消。
- “恢复原分辨率”在一键模式期间也会执行完整桌面恢复。一键模式期间不能清除恢复记录。窗口内容可上下滚动；右上角齿轮打开设置。
- 本版沿用上游对全部当前连接监视器的禁用范围。多屏用户请知悉开启会处理全部已启用的监视器；部分笔记本禁用期间无法调节亮度。

## 修改内容与验证

新增一键开启、一键恢复、设备状态逐项核对、持久恢复记录、失败撤回，以及游戏退出和窗口关闭的完整恢复。用设备问题码 22 判断“已禁用”，避免把其他设备错误显示成已禁用；查询失败会明确显示。保留中文界面、离线内置页面、快捷键、预设、黑边修复和原有设置兼容性。

通过 Python 模拟回归和浏览器界面验证，覆盖操作顺序、原先禁用设备的保留、取消权限、部分失败、恢复重试、重启后恢复，以及快捷键和退出游戏恢复配合。具体数量和原生启动结果见 `验证记录.json`。

验证使用模拟设备或临时设置，原生启动验证关闭自动恢复和快捷键。没有改变当前电脑的真实分辨率、监视器或显卡注册表配置。尚未实测游戏内效果，也未在另一台干净 Windows 电脑验证。

## 从源码构建

建议使用 Windows x64、Python 3.12（含 Tkinter），以及 WebView2 运行时。

在本目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

也可以手动执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean EasyTS-zh-CN.spec
```

结果位于 `dist\EasyTS-zh-CN.exe`。`constraints.txt` 保存本次完整依赖版本；打包配置将中文页面、图标与需要的运行库一并收集。最终程序仍依赖系统 WebView2 和适用的 .NET 运行时。
